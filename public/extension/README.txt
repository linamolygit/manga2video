Panel Reel Saver — browser extension
====================================

Finds image URLs on the page you already have open.
Save one image (original filename) or all as a numbered zip (001_name.jpg).
Nothing is uploaded. The extension only runs when you click it.

Install (Chrome / Edge / Brave)
1. Unzip this folder if you downloaded a zip.
2. Open chrome://extensions (or edge://extensions).
3. Turn on Developer mode.
4. Load unpacked → select this folder (the one with manifest.json).

Then open a page, click the Panel Reel icon, Save or Save numbered zip.
Drop those files into Panel Reel to make a slideshow video.
